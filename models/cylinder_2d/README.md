# COMSOL model placement

Save your **locally validated** `.mph` model here as `cylinder_base.mph`.

No `.mph` model is supplied because a valid model requires a real COMSOL installation, mesh, physics settings, a verified volume-force term, and benchmark results. `*.mph` files are deliberately ignored by Git.

See [`../../docs/COMSOL_MODEL_CONTRACT.md`](../../docs/COMSOL_MODEL_CONTRACT.md).
