## 实验设计与执行入口

[运行入口](../scripts/run_re100_s1b2_mesh.py) 使用 [显式 M1 配置](../configs/re100_s1b2_m1.json)，从实际 M0 回读的尺寸控制出发，将全局及圆柱边界的 `hmax/hmin` 除以 1.4。细化比例作用于尺寸控制，不要求非结构网格的每一条边都恰好缩短到原来的 1/1.4。保留原网格生成算法、选择、增长与曲率控制，实际调用 COMSOL 原生网格构建；输出采样时间表继续为 `range(0, 0.2, 200)`。

COMSOL 的 `custom=on` 用于启用自定义网格参数，`hmax/hmin` 是实际网格生成尺寸控制；此处通过原生 `mesh.run()` 构建细化网格。[COMSOL Size API](https://doc.comsol.com/6.4/doc/com.comsol.help.comsol/comsol_api_mesh.49.100.html)、[COMSOL Mesh 编程说明](https://doc.comsol.com/6.4/doc/com.comsol.help.comsol/application_programming_guide.15.24.html)。

NASA 的空间收敛指南允许非整数细化比，并建议保留原网格生成方法、检查壁面及其他代表性尺度；三档解可用于估计观测收敛阶和检查渐近区间。因此本轮将两档比较限定为初步敏感性诊断，不估计收敛阶、GCI 或真解误差。[NASA NPARC 空间网格收敛指南](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)。

## 实际网格与测量方法

M1 构建后和求解后的原生网格核验均通过；五项控制修改与实际回读一致，求解前后的顶点、连接关系和网格控制保持相同。控制变化如下：

| `size1.hmax` / m | 0.0004 | 0.000285714285714 |

圆柱边界沿用 `[5, 6, 7, 8]`。边界层节点 `bl1/blp1` 保留 `inittype=blhminfact`、`blhminfact=5`、`blnlayers=2`、`blstretch=1.2`。这两层是既有基线设置，本轮没有新增层数或将其宣称为已完成壁面分辨率验证。

在该自动模式下，`blhminfact` 才是生效控制；`blhmin` 和 `blhtot` 的非激活默认读数不作为实际首层高度或总厚度。COMSOL 官方文档区分了这三种厚度控制模式，并说明默认厚度与网格尺寸有关。[COMSOL BndLayerProp API](https://doc.comsol.com/6.4/doc/com.comsol.help.comsol/comsol_api_mesh.49.057.html)。报告的首层高度从原生坐标和连接关系测量：对每条圆柱壁面边找到相邻四边形，取两个非壁面顶点到壁面弦线的垂直距离均值，不假定四边形顶点排列顺序。
