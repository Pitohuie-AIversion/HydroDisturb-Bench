## 七、 结论边界与后续推进建议

1. **四网格对比结论**：
   在保持时间容差 $rtol=10^{-4}$、最大时间步长 $0.05\text{ s}$、P1+P1 离散和流动物理设置完全一致的前提下，经过四档原生网格细化（$N = 7,493 \to 11,930 \to 19,982 \to 34,752$），相邻步 **M2 vs M3** 的四项核心指标变化率分别为：
   - $St$: **+0.79%**（$<1.0\%$，通过）
   - $C_D$: **+0.34%**（$<1.0\%$，通过）
   - 升力半振幅: **+0.69%**（$<1.0\%$，通过）
   - 升力 RMS: **+0.70%**（$<1.0\%$，通过）
   四项核心指标全部严格小于 1.0% 的工程验收红线。
2. **渐近态势与增量缩减**：
   四项指标在最新一步中全部表现出绝对增量缩减（$|\Delta_{23}| < |\Delta_{12}|$），其中升力波动指标增量衰减达 $62.4\%$，表明计算结果已经进入平滑收敛的稳定通道。
3. **误差外推与 GCI 边界**：
   本轮先报告四档网格敏感性；由于非结构三角形/四边形混合网格在全局及远尾流区域的实际局部细化比与名义控制比存在一定分散性，尚未建立无可争议的单一代表网格尺度与空间收敛阶次，因此不进行外推性 Richardson 外推、形式化 GCI 宣称或假定真解误差界。
4. **后续研究建议**：
   - 当前网格敏感性已满足相邻步 $<1.0\%$ 且增量收敛的标准，空间网格验证阶段具备收尾条件；
   - 依据 COMSOL 官方指导，在最终选定生产网格（如 M2 或 M3）上，可进行一次高精度时间步长抽查（例如最大步长由 $0.05\text{ s} \to 0.025\text{ s}$），完成时空离散精度的交叉闭环；
   - 后续阶段可转入远场边界条件（外边界阻塞比效应）或外加水动力扰动响应的基准测试。
