# 局部体力参数设置

本入口对应阶段规划中的“局部定向高斯体力”。编辑 [m3_local_pulse.json](../configs/m3_local_pulse.json)，即可设置位置、方向、加速度强度、高斯宽度和起止时间。入口先校验参数，再由 COMSOL 实际节点回读和源项求值核验，随后从已有共同原生起点生成一个新未来。

## 用户参数

| 配置字段 | 默认值 | 含义与当前允许范围 |
| --- | --- | --- |
| `event_id` | `m3-local-pulse-default` | 1–64 位 ASCII 字母/数字/下划线/连字符，首位字母或数字；仅为事件身份 |
| `pulse.center_m` | `[0.15,0.12]` | 模型全局坐标 `[x,y]`，单位 m；不是相对圆柱中心的 D 坐标 |
| `pulse.direction_deg` | `90` | 从 +x 逆时针计角，范围 −180° 到 180°；0=顺流，90=向上，−90=向下，±180=逆流 |
| `pulse.acceleration_m_s2` | `0.005` | 中心峰值加速度 A，范围 0–0.010 m/s²；反向用角度设置，A 不使用负值 |
| `pulse.sigma_m` | `0.01` | 高斯标准宽度 σ，范围 0.005–0.020 m；不是硬截断半径 |
| `pulse.on_s` | `181` | 开始时间，严格晚于共同起点 180 s |
| `pulse.off_s` | `183` | 结束时间，严格晚于 on 且早于 200 s |

起止时间须精确对齐 0.2 s 保存表，持续时间须为 0.4 s 的整数倍，使中点峰值也有保存帧。程序拒绝不对齐值，不四舍五入或取最近时刻。JSON 仅接收有限数字，拒绝公式字符串、未知字段、重复键和布尔值。

模型范围为 x∈[0,0.40] m、y∈[0,0.24] m，圆柱中心 (0.10,0.12) m、半径 0.005 m。用于准入的 **3σ 圆盘必须完全在矩形内，并与圆柱严格分离**；可以接触矩形边界，不能接触圆柱。3σ 以外仍有高斯尾部，实际源项没有截断；积分覆盖整个真实流体域。

上述范围是首版工程准入规则。它保证支持的配置形式和检查路径明确，不表示已验证范围内所有组合的 CFD 精度或响应可辨识性。

## 实际施加的源项

令 θ 为方向角，`d=(cos θ,sin θ)`，空间包络为

```text
G(x,y) = exp(-((x-xc)^2+(y-yc)^2)/(2*sigma^2))
E(t)   = sin(pi*(t-on)/(off-on))^2,  on < t < off
         0,                       其他时刻
F      = rho_f * A * G * E * [dx,dy,0]
```

A 单位为 m/s²，实际 VolumeForce 单位为 N/m³。空间积分为每单位厚度的 N/m，时间积分为 N·s/m；这些是施加源项，不是流体净动量变化。σ 偏移点的峰值为中心峰值乘 `exp(-1/2)`，用于核对宽度与坐标是否真正接入。

只调整本表参数。已有 M3 原生网格、几何、物性、入口、共同 `sol1/901/180 s` 起点，以及 `rtol=1e-4 / const / 0.05 s / consistent=off` 保持本轮固定协议。输出仍为 180–200 s、0.2 s 间隔、101 帧，采样仍为 `(101,3,97,161)`。旧实验及幅值系列的冻结入口保留，不能通过改旧计划哈希开放参数。

## 运行与分阶段检查

在持有历史数据的主仓库根目录运行，输出使用新的目录：

```powershell
# 仅校验配置、源文件身份并冻结本次计划；不加载模型
python -X utf8 scripts/run_m3_local_pulse.py --config configs/m3_local_pulse.json --output runs/my_local_pulse_01 --stage precheck

# 加载共同 checkpoint，执行 Variables 和真实源项求值；不执行 Time
python -X utf8 scripts/run_m3_local_pulse.py --config configs/m3_local_pulse.json --output runs/my_local_pulse_01 --stage inspect

# 参数核验后实际续算、采样，并与已有零分支/连续基线比较
python -X utf8 scripts/run_m3_local_pulse.py --config configs/m3_local_pulse.json --output runs/my_local_pulse_01 --stage all
```

`solve`、`sample`、`analyze` 可分别运行。`sample/analyze` 要求已有完成且验证通过的求解，不会为了读取结果自动发起新的 Time 求解。同一目录只能恢复同一配置和来源；修改任何参数后使用新目录。冻结计划与 properties 都参与哈希核验，不覆盖已有成功或失败文件。

## 小规模参数矩阵预注册

[`m3_local_pulse_sweep.json`](../configs/m3_local_pulse_sweep.json) 登记三个案例：默认 +y、对角线调试案例和 −y；登记入口本身不执行 COMSOL。`pulse_sweep` 会校验基础配置哈希、每个案例的六个物理参数、事件身份和重复的物理配置，并生成带哈希的轻量 manifest；它不加载模型、不创建模型、不生成场张量。所有案例仍属于同一个 M3 checkpoint 祖先族，不能因参数不同就当成独立测试族。每个案例实际续算时必须使用新的输出目录，并分别保存真实回读与求解证据。

`inspect` 将节点实际返回的 Fx/Fy/Fz 表达式以 `subst` 替换时间，检查开始前、起点、峰值、终点与结束后。这是对**规定源项**的独立求值：用于求值的原生解时间仍为 180 s，不能把诊断时间当成已经求解的未来流场。`solve` 完成后另行读取真实 101 个时刻的源项和内部步进日志。

正幅值分支比较新事件与已有零分支，零分支与连续基线用于估计重启差异；空间 ROI 按本次中心 ±3σ 冻结，响应窗口为 `(on,min(off+3,200)] s`。沿用已定义的重启/响应门槛，响应不足时如实失败，不自动加大强度或放宽阈值。A=0 是无事件对照，检查其全段差异不超过规定噪声界，不要求出现非零响应。

## 2026-11-09 方向与持续时间对照

本次只补充反向和两档持续时间，复用已完成的默认 +y／2 s 分支及零分支。四案共同固定中心 `(0.15,0.12) m`、`A=0.005 m/s²`、`sigma=0.01 m`、`on=181 s`，从同一 M3 原生 `sol1/901/180 s` checkpoint 启动，沿用现有网格、时间积分和采样契约，每案仍为 `(101,3,97,161)`。

| 案例 | 方向 | 持续时间 | 结束时刻 | 配置与来源 |

三个新增案例均已完成真实 COMSOL `inspect/solve/sample/analyze`，逐案核验通过；各有 457 个接受的内部步、实际最大步长 0.05 s 和 101 帧输出。原有 824 个历史文件的哈希保持一致。共同窗口比较与本轮回归的完整结果以阶段报告为准。

各新增案例首先保留自己的原响应窗口与既定门槛，再用共同 ROI `[0.12,0.18,0.09,0.15] m` 和响应窗口 **`(181,188] s`** 进行横向比较。报告给出各案相对零分支的响应、同 ROI 重启噪声，以及新增案减默认案的差异。历史幅值报告采用不同 ROI／窗口，其旧峰值不能直接代入本次比较；默认案必须由原场数据按本次共同口径重算。反向施力不等于流场响应逐点反号，持续时间改变也不预设响应与源冲量成线性关系。

只读入口为 [compare_m3_pulse_direction_duration.py](../scripts/compare_m3_pulse_direction_duration.py)。它要求 `--plan`、`--expected-sha256` 和新 `--output`，通过 `--data-root` 定位已有原生模型与完整场数据；核对冻结配置、旧引用文件、实际回读与步进、模型和采样来源后重新比较，不启动 COMSOL。阶段状态、命令和证据入口见 [方向／持续时间报告](reports/M3_PULSE_DIRECTION_DURATION_20261109.md)。

反向案例采样曾在目录发布时出现 `WinError 5`。原失败记录保留；核验 staging 中 117 个文件和七个数组后仅重试发布并成功，没有重新求解或重新采样。这是已核验产物的发布恢复，不代表该 Windows 偶发失败的根因已修复。

## 数据与交付

需要原本地 checkpoint、prepare 来源证据、baseline 和 zero 场数据。`--data-root`/`HYDRO_DATA_ROOT` 只定位已登记相对路径，不自动改写历史绝对路径或身份。现有源模型和历史结果保持原位；新 MPH、原生向量、完整采样数据保存在新运行目录。

新分支仍属于同一 M3 祖先族。将它加入数据窗口索引时须与既有 baseline/zero/幅值分支保持同族，不能仅因参数不同就分到独立测试集。PDF 中的入口变化、旋涡、移动源、复合事件、旋转/移动几何以及 16+64 训练候选规格不属于本轮实现范围。
